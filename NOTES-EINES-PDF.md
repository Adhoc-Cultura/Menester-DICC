# Eines PDF de les recomanacions

L'app cita, a cada àmbit, una eina PDF descarregable. Cal col·locar aquests
fitxers a la carpeta `public/` perquè es puguin enllaçar (i, si voleu que siguin
clicables, es pot afegir un enllaç al codi més endavant).

Fitxers esperats (noms tal com apareixen a l'app):

- OBRIR        → ara-cultura-obertura.pdf
- CONNECTAR    → ara-cultura-mapa-agents.pdf
- COCREAR      → ara-cultura-disseny-cultural-1.pdf
- EXPERIMENTAR → ara-cultura-disseny-cultural-3.pdf
- ARRELAR      → Canvas_Adhoc_Cultura.pdf

De moment l'app mostra el NOM de l'eina com a text. Quan tingueu els PDF,
poseu-los a `public/` i aviseu per convertir-los en enllaços de descàrrega.
